Carpeta del cliente

  1. Presiona Windows + E para abrir el Explorador de archivos.
  2. Haz clic en la barra de dirección de arriba (o presiona Ctrl + L).
  3. Pega la ruta con Ctrl + V y presiona Enter.

¿Qué quieres exportar?

Elige las columnas para la hoja de 8,5 × 13. Siempre se incluyen el N°, la unidad, el cliente y la situación. Se exportan los clientes que tengas filtrados.

Reporte del cliente

Elige el formato. El PDF es el mejor para imprimir; el PNG es una imagen para enviar por WhatsApp o correo.
